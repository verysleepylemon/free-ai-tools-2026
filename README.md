## 💬 Prompt Engineering

### The Universal Mega-Prompt Template

```
You are an expert [ROLE] with [X] years of experience.
Your task: [CLEAR TASK DESCRIPTION]
Context: [RELEVANT BACKGROUND]
Constraints: [WHAT TO AVOID]
Output format: [HOW YOU WANT IT]
Examples: [GOOD EXAMPLES IF ANY]
```

### Essential Prompts for Developers

**Debug Any Code:**
```
Here is my code:
[CODE]

It produces this error:
[ERROR]

Explain the root cause in 1 sentence, then provide the minimal fix.
```

**Code Review:**
```
Review this [LANGUAGE] code for:
1. Security vulnerabilities (OWASP Top 10)
2. Performance issues
3. Readability improvements

Code: [CODE]

Be concise. Only flag real issues.
```

**Write Tests:**
```
Write pytest unit tests for this function:
[FUNCTION]

Cover: happy path, edge cases, error cases.
Use AAA pattern. No mocking unless necessary.
```

**Explain Any Code:**
```
Explain this code like I'm a senior dev who hasn't seen this codebase:
[CODE]

Focus on: what it does, why it does it that way, and any gotchas.
```

**Write a README:**
```
Write a GitHub README for this project:
- Name: [NAME]
- What it does: [DESCRIPTION]
- Tech stack: [STACK]
- Target audience: [WHO]

Use badges, emojis sparingly, include install + quickstart sections.
```

**System Design:**
```
Design a [FEATURE] for a system that handles [SCALE].
Constraints: [CONSTRAINTS]

Output: brief architecture diagram (text), key components, database schema, 
and top 3 scaling concerns.
```
